# Android Frontend

This folder contains the complete Android Studio project for the AI-Based Research Publication Management and Analytics System.

## Project Name

AIResearchManager

## Technologies Used

- Java
- Android Studio
- Volley
- Gson
- MPAndroidChart

## Features

- Faculty Search
- Publication Search
- ORCID Search
- Citation Analytics
- H-Index Calculation
- I10-Index Calculation
- Research Analytics Charts

## Backend API

https://ai-based-research-publication-management.onrender.com

## Run Project

1. Open AIResearchManager folder in Android Studio
2. Sync Gradle
3. Run on Emulator or Physical Device
