# AI-Based Research Publication Management and Analytics System

## Overview

This project is an Android and Flask-based Research Publication Management and Analytics System that helps users search faculty publications, view citation metrics, and analyze research performance through interactive dashboards.

## Features

* Faculty Search
* ORCID Search
* Publication Search
* Citation Analytics
* H-Index Calculation
* I10-Index Calculation
* Publication Trend Analysis
* Research Domain Analytics

## Technologies Used

### Frontend

* Android Studio
* Java
* Volley
* Gson
* MPAndroidChart

### Backend

* Python
* Flask
* Pandas

### Deployment

* Render Cloud Platform
